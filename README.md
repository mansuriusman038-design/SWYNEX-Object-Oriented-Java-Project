SWYNEX Object-Oriented Java Project

Student Management System

This project is developed using Java to demonstrate the four main Object-Oriented Programming (OOP) concepts.

Features

- Add student records
- View student details
- Delete student records
- Check Pass/Fail status
- Support regular and graduate students

OOP Concepts Demonstrated

1. Encapsulation

Student data is kept private and accessed through methods.

2. Inheritance

The Student class extends Person, and GraduateStudent extends Student.

3. Abstraction

The abstract Person class defines the displayDetails() method.

4. Polymorphism

The displayDetails() method is overridden for different student types.

Technologies Used

- Java
- Object-Oriented Programming
- VS Code

How to Run

1. Open the project folder in VS Code.
2. Compile the Java files.
3. Run the Main class.
